动机

熵不等于歧义。

现有自适应水印根据预测熵决定嵌入位置。但熵同时混合了偶然不确定性——上下文本身的歧义——与认知不确定性，后者反映的是模型“不知道”的部分。AAW 关注的是后者。

在高歧义位置，预测熵反而更低（2.04 vs 2.86），而 Monte Carlo dropout 得到的歧义分数高出一个数量级（3.35e-7 vs 2.99e-8）。因此，仅依赖熵的门控会错过最容易检测水印的位置。

熵问的是“模型有多不确定”，歧义问的是“模型为什么不确定”。

亮点

AAW 有效的四个原因。

AAW 不是嵌得更多，而是嵌在模型真正歧义的位置，并用能抵抗改写的语义载荷承载水印。

亮点 1

稀疏，而非密集

AAW 只选择同时通过熵门控与歧义门控的位置，而不是对所有低熵 token 嵌入水印。

38.7 个水印 token，对比仅熵门控 62.8

亮点 2

歧义，而非熵

高歧义位置的预测熵更低，但 Monte Carlo 歧义分数高出一个数量级。

2.04 熵 vs 2.86 · 3.35e-7 歧义度 vs 2.99e-8

亮点 3

质量与鲁棒性兼得

AAW 的困惑度更接近未加水印模型，同时在改写攻击下取得更好的排序。

0.951 GPT 改写 ROC-AUC · 7.66 PPL vs 8.74

亮点 4

检测保持公开

检测端只需要公开辅助模型与 SP-Net，不需要访问私有 LLM。

0 次私有 LLM 调用 · 仅公开 MM + SP-Net

  • 水印 token 减少 38.4% — 38.7 vs 62.8，同时检测更强。
  • 检测分数 +37 — 87.18 vs 未加水印 50.38。
  • 0.951 ROC-AUC — GPT-3.5 改写攻击下，对比 Adaptive 0.918、KGW 0.883、MorphMark 0.838。
  • 文本质量优于 Adaptive — PPL 7.66 vs 8.74，Log Div 10.67 vs 7.95。
  • 检测不需要私有模型 — 仅使用公开辅助 MM 与 SP-Net。

方法

少嵌水印，嵌在关键位置。

AAW 由层级门控、语义载荷与质量保持调制组成。检测端不需要访问私有 LLM。

1

在哪里：熵预筛选 → 歧义定位

公开辅助模型计算预测熵，只有低熵候选通过。随后对每个候选执行 N = 8 次 Monte Carlo dropout，估计认知不确定性；歧义度高于 τA 的位置被保留。仅当两个条件同时满足时，门控 gt 为 1。

结果：38.7 个水印 token，比仅熵门控（62.8）少 38.4%。

2

嵌什么：语义载荷 + 乘性调制

Sentence-BERT 编码器与 SP-Net 将局部上下文映射为二进制载荷 qt。在选中的位置，AAW 对原始 logits 进行缩放。由于调制是乘性的，它保持了下一个 token 分布的形状。

L′t = Lt ⊙ (1 + gt · δ · qt),   δ = 0.5
3

如何检测：模型无关检测

检测端只需要公开辅助 MM 与 SP-Net。它从文本中重新识别候选位置，重建载荷并统计匹配数 k。对零假设做 z 检验即可得到最终判断——无需访问私有 LLM。

z = (k − m/2) / √(m/4)

消融

两个门控都重要。

去掉任一 gate 都会变差。AAW00 不使用门控，AAW01 只使用歧义，AAW10 只使用熵，AAW11 同时使用两者。歧义门控是改写鲁棒性的主要来源，熵门控在强删除攻击下尤其有用。

变体 熵门控 歧义门控 改写 AUC ↑ 组合攻击 AUC ↑
AAW00 — — 0.883 0.863
AAW01 — ✓ 0.944 0.871
AAW10 ✓ — 0.918 0.892
AAW11 ✓ ✓ 0.951 0.932

消融说明了什么

仅歧义 AAW01 将改写 AUC 从 0.883 提升到 0.944；仅熵 AAW10 将组合攻击 AUC 从 0.863 提升到 0.892。两者结合在两个指标上都最好：改写 AUC 0.951 与 组合攻击 AUC 0.932。

AAW11 使用 38.7 个 token，而 AAW10 使用 62.8 个，因此提升并不是靠更密集的水印换来的。

结论

选对位置，少即是多。

AAW 把“嵌得更多”换成“嵌在关键位置”：稀疏的高歧义位置、语义载荷与公开检测器。结果是更少的水印 token、更好的文本质量，以及更强的改写鲁棒性。

局限性。 Monte Carlo dropout 带来额外推理开销（每个候选 N = 8 次前向）。降低这部分成本是自然的下一步。
