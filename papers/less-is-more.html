Motivation

Entropy is not ambiguity.

Existing adaptive watermarks decide where to embed by predictive entropy. But entropy conflates aleatoric uncertainty — the inherent ambiguity of the context — with epistemic uncertainty, which reflects what the model does not know. AAW targets the latter.

At high-ambiguity positions, predictive entropy is actually lower than at low-ambiguity positions (2.04 vs 2.86), while Monte Carlo dropout exposes an ambiguity score an order of magnitude higher (3.35e-7 vs 2.99e-8). Entropy-only gating therefore misses the positions where a watermark is easiest to detect.

Entropy asks how uncertain the model is. Ambiguity asks why it is uncertain.

Method

Watermark less, where it matters.

AAW combines a hierarchical gate, a semantic payload, and a quality-preserving modulation. The detector needs no access to the private LLM.

1

Where: entropy pre-filter → ambiguity pinning

A public auxiliary model measures predictive entropy. Only low-entropy candidates pass. For each candidate, N = 8 Monte Carlo dropout passes estimate epistemic ambiguity; positions above τA are kept. The gate gt is 1 only when both tests agree.

Result: 38.7 watermark tokens, 38.4% fewer than entropy-only gating (62.8).

2

What: semantic payload + multiplicative modulation

A Sentence-BERT encoder and SP-Net map the local context to a binary payload qt. At selected steps, AAW scales the original logits. Because the modulation is multiplicative, it preserves the shape of the next-token distribution.

L′t = Lt ⊙ (1 + gt · δ · qt),   δ = 0.5
3

How: model-agnostic detection

The detector only needs the public auxiliary MM and SP-Net. It re-identifies candidate positions from the text, regenerates the payload, and counts matches k. A z-test against the null gives the final decision — no private LLM access required.

z = (k − m/2) / √(m/4)

Ablation

Both gates matter.

Removing either gate hurts. AAW00 has no gate, AAW01 uses only ambiguity, AAW10 uses only entropy, and AAW11 uses both. Ambiguity gating is the main driver of paraphrase robustness, while entropy gating is especially useful under aggressive deletion.

Variant Entropy Ambiguity Paraphrase AUC ↑ Combined-medium AUC ↑
AAW00 — — 0.883 0.863
AAW01 — ✓ 0.944 0.871
AAW10 ✓ — 0.918 0.892
AAW11 ✓ ✓ 0.951 0.932

What the ablation says

Ambiguity-only AAW01 raises paraphrase AUC from 0.883 to 0.944. Entropy-only AAW10 improves the combined-medium attack from 0.863 to 0.892. Combining both gates gives the best result on both fronts: 0.951 paraphrase AUC and 0.932 combined-medium AUC.

AAW11 also uses 38.7 tokens versus 62.8 for AAW10, so the gain is not bought with a denser watermark.

Conclusion

Less is more — if you choose the right positions.

AAW replaces “watermark more” with “watermark where it matters”: a sparse set of epistemically ambiguous positions, a semantic payload, and a public detector. The result is fewer watermark tokens, better text quality, and stronger robustness to paraphrasing.

Limitation. Monte Carlo dropout adds inference overhead (N = 8 forward passes per candidate). Reducing this cost is a natural next step.
