Abstract

Ownership checks read behavior, not provenance.

Model watermarking supports intellectual-property claims by verifying a model's responses to a secret key set. But this behavior-only interface is vulnerable to fabricated evidence. FakeMark is a gradient-guided false-claim attack for image classifiers that uses a white-box surrogate yet never queries or accesses the victim model during attack construction.

The method caches selected convolutional and fully connected outputs from clean surrogate batches and injects them through stochastic multi-layer, channel-wise interpolation. Across 16 architectures, an adversarially trained ResNet-50 checkpoint, and eight watermark variants, retrospective best-case behavioral target-label accuracy reaches 1.00 on CIFAR-10 and 0.99 on ImageNet. Matched baselines and detector analyses motivate provenance-aware, multi-factor ownership protocols.

Motivation

A trigger response is not proof of training.

A verifier observes that a model reacts to a key set. That tells us what the model does — not who trained it, or how the key set was made.

1

Only the interface is checked

Ownership is accepted when trigger inputs reproduce the verification labels. The verifier never sees how those inputs were produced.

2

No victim access is needed

FakeMark optimizes forged keys on a white-box surrogate. The victim is touched once, for the final behavioral score.

3

The budget stays realistic

Every forged key is projected onto an ℓ∞ ball of radius ε = 16/255: a bounded perturbation, not a backdoor insertion.

A successful trigger response shows that the model behaves in a certain way; it does not show why.

Threat model. The attacker has white-box gradients of one or more public surrogates, the public data distribution, the behavioral form of the verification interface, and a chosen target label. The attacker has no queries, gradients, parameters, or architecture of the victim, and no access to the legitimate key.
Method

Cache clean features, fuse them stochastically.

Two stages: record clean module outputs from the surrogate, then interpolate them into the forward pass while optimizing a target logit.

1Cache clean references

Run a clean batch through the surrogate and store pre-activation outputs of selected convolutional layers, plus the final fully connected layer.

2Fuse across layers and channels

Randomly gate modules, permute the batch dimension, and interpolate each channel with a fresh coefficient α ~ U(0, αmax).

3Optimize the target logit

Apply PGD to the input batch under an ℓ∞ budget, so every forged key maximizes the chosen target class while staying bounded.

Reading the numbers. These are retrospective best-case maxima over the audited surrogate pool, not an operational guarantee that a high-transfer surrogate can be picked without victim feedback. On ImageNet, transfer ranges from near zero (ResNet18, VGG16) to 0.99 (ResNet-50 L2), so architecture and checkpoint compatibility is the central condition.

Takeaways

What this means for ownership verification.

Implication

Behavior is not provenance

A successful trigger response cannot distinguish a legitimate owner from a well-constructed forger. The arbiter sees the behavior, not its origin.

Condition

Compatibility beats capacity

MobileNetV2 matches ResNet50 at 0.990, Inception-v3 reaches 0.727, and some ImageNet pairs stay near zero. Model size alone does not explain transfer.

Protocol

Verify with multiple factors

Pair behavioral tests with cryptographic commitments to keys or provenance, structural fingerprints, and validation under post-processing.

Limitations. FakeMark assumes white-box surrogate gradients and dataset-level overlap; CIFAR-10 surrogates and targets also share the standard training split. The linear analysis is explanatory, the main tables use one fixed target label, and the study is limited to image classification.
